# Contributor Covenant Code of Conduct

We are committed to a harassment-free, inclusive community. Be respectful, assume
good faith while verifying technical claims, accept evidence-based disagreement, and
do not expose another person's private information or security report.

Unacceptable behavior includes harassment, discriminatory language, threats,
deliberate intimidation, publication of private information, and sustained disruption.
Maintainers may edit, reject or remove contributions and participation that violate
these expectations. Enforcement actions should be proportionate, documented privately,
and avoid disclosing reporters unnecessarily.

## Reporting and enforcement

For conduct occurring on GitHub, use GitHub's private
[report-abuse flow](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
For a project-specific moderation concern that is safe to state publicly, open an
issue without including private information. This single-maintainer, pre-1.0 project
does not yet operate a separate private conduct inbox; that is a disclosed governance
limitation, not an invitation to send sensitive details through a public channel.
Security vulnerabilities must use the private process in `SECURITY.md` instead.

This concise policy is adapted from the Contributor Covenant 2.1 principles.
