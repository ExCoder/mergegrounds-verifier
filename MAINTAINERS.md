# Maintainers and governance

This pre-1.0 reference implementation is currently bootstrapped by one public
maintainer, `@ExCoder`; it does not claim independent governance. Before any
production deployment or multi-maintainer trust claim, replace the single-owner
CODEOWNERS entries with real GitHub teams containing at least two people, name
security responders, and document decision/removal/succession rules here.

No single contributor should be able to modify protected policy, verifier code,
decision identity and branch rules without independent review. Emergency bypass must
be time-bounded, audited and followed by retrospective review.
